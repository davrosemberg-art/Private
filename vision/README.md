# Vision commerciale VAV Le Studio

Proposition à l'attention de la direction de Voyage avec Vue.
Horizon : novembre 2026 à fin 2027.

On a trois ans de travail derrière nous, une audience, une collection d'adresses, une équipe de production. Ce qui manque, c'est une façon simple et ordonnée de vendre. Ce dossier pose cette façon de faire, autour d'une offre phare : le **Carnet d'adresse**.

## Sommaire

1. [Cadre et diagnostic](01-cadre-et-diagnostic.md) : ce qu'on couvre, ce qui coince aujourd'hui.
2. [L'offre Carnet d'adresse](02-offre-carnet-d-adresse.md) : ce qu'on vend, à quel prix, à quelles conditions.
3. [La vente](03-vente.md) : la promesse, les cibles, les canaux, la méthode.
4. [Le pilotage](04-pilotage.md) : l'objectif chiffré et comment on le suit.

Les chantiers concrets qui découlent de cette vision sont suivis dans les issues GitHub du repo.
